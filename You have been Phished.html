How to Stay Safe

Follow these best practices while handling emails and external communications.

✓

Do

✓ Verify sender email addresses carefully.
✓ Hover over links before clicking them.
✓ Report suspicious emails to the IT Security team.
✓ Validate urgent requests through official channels.
✓ Check attachments and file extensions carefully.
✓ Use strong passwords and MFA wherever possible.
✕

Don't

✕ Do not click unverified or shortened links.
✕ Never share passwords through email.
✕ Do not trust urgent requests without verification.
✕ Avoid downloading unexpected attachments.
✕ Never enter credentials on suspicious websites.
✕ Do not ignore security warnings or alerts.

Security Starts With Awareness

Phishing attacks continue to evolve every day. Staying alert and following security best practices helps protect both personal and organizational information.
